# Проверяющие агенты Codex

В `.codex/agents/` лежат четыре проектных агента для проверки сайта с разных точек зрения:

- `child_7_9` — ребёнок 7–9 лет;
- `teen_13_15` — подросток 13–15 лет;
- `mama_0_3` — мама малыша 0–3 лет;
- `clinician` — медсестра или врач детского отделения.

Codex обнаруживает эти файлы автоматически после открытия и подтверждения доверия к проекту. Дополнительная регистрация не нужна.

## Запуск

Попросите Codex, например:

> Проверь сайт https://childpage-gamma.vercel.app/ агентом `teen_13_15`. Проведи проверку в мобильном размере 390×844, дождись фактической загрузки страниц и верни отзыв в заданном формате.

Чтобы экономить лимит, запускайте агентов по одному. Параллельный запуск всех четырёх тратит больше токенов. Если браузер недоступен или проверка не удалась, агент должен сообщить об этом, а не описывать непроверенные действия.

Инструкции агентов про запрет изменений — не техническое ограничение. Для проверок переключите родительскую сессию Codex в режим только чтения; агенты наследуют её разрешения.

## Проверки и скриншоты

Если при отдельной проверке сохраняете скриншоты или временные отчёты, складывайте их в `.codex/reviews/`. Эта папка исключена из Git: локальные тестовые материалы не попадут в публикацию сайта.
